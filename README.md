# Slide Extractor

강의 영상을 분석해 **슬라이드만 추출한 PDF**로 만들어주는 CPU 기반 도구입니다.

온라인 강의나 녹화 강의처럼 화면 대부분이 프레젠테이션 슬라이드로 구성된 영상에서, 슬라이드가 바뀌는 시점을 자동으로 찾아 중복 없이 PDF로 정리합니다.

## 이런 경우에 유용합니다

- 긴 강의 영상을 슬라이드 PDF로 빠르게 정리하고 싶을 때
- 원본 PPT/PDF는 없고 녹화 영상만 가지고 있을 때
- 화면 양옆의 검은 여백이나 레터박스를 제외하고 슬라이드 영역만 저장하고 싶을 때
- 같은 슬라이드가 여러 번 등장하는 강의에서 중복 페이지를 줄이고 싶을 때

## 동작 방식

```text
강의 영상
   ↓
슬라이드 영역 자동 감지
   ↓
슬라이드 변경 시점 탐지
   ↓
안정적으로 유지된 대표 프레임 선택
   ↓
중복 슬라이드 제거
   ↓
PDF 생성
   ↓
qpdf로 PDF 용량 최적화
```

비교 단계에서는 작은 이미지를 사용해 처리량을 줄이고, 최종 PDF에 넣을 프레임은 원본 영상 해상도에서 다시 추출합니다.

슬라이드 크기는 특정 해상도로 고정하지 않습니다. 영상마다 자동으로 감지한 슬라이드 영역의 크기를 그대로 사용합니다.

## 요구 사항

- Python 3.12 이상
- FFmpeg / ffprobe
- qpdf

Ubuntu / Debian에서는 다음과 같이 설치할 수 있습니다.

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg qpdf
```

## 설치

저장소를 받은 뒤 프로젝트 폴더에서 실행합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

## 사용법

가장 기본적인 사용법입니다.

```bash
python -m slide_extractor lecture.mp4
```

결과는 현재 작업 폴더의 `output/` 아래에 생성됩니다.

```text
output/lecture.slides.pdf
```

`output/` 폴더가 없으면 자동으로 생성됩니다.

### 출력 파일 직접 지정

```bash
python -m slide_extractor lecture.mp4 --output my-slides.pdf
```

### 슬라이드 영역 직접 지정

자동 감지가 잘 맞지 않는 영상은 원본 영상 기준으로 `x,y,width,height`를 지정할 수 있습니다.

```bash
python -m slide_extractor lecture.mp4 --roi 100,20,1280,720
```

### 샘플링 속도 조절

기본값은 초당 1프레임입니다. 변화가 느린 강의는 0.5 FPS로 낮출 수 있습니다.

```bash
python -m slide_extractor lecture.mp4 --sample-fps 0.5
```

### 중간 결과 보존

분석 과정에서 만들어진 중간 파일을 확인하려면 다음 옵션을 사용합니다.

```bash
python -m slide_extractor lecture.mp4 --keep-workdir
```

## PDF 용량 최적화

생성된 PDF는 마지막 단계에서 qpdf로 한 번 더 최적화됩니다.

이 과정에서는 슬라이드 해상도를 임의로 특정 크기로 변경하지 않고, PDF 내부 이미지와 스트림을 효율적으로 다시 압축합니다.

실제 검증 사례 중 하나에서는 동일한 49페이지 PDF가 약 **101.6 MB에서 19.3 MB로 감소**했습니다. 압축 효과는 강의 영상과 슬라이드 내용에 따라 달라질 수 있습니다.

## 참고 사항

이 도구는 **정적인 슬라이드 중심의 강의 영상**을 대상으로 합니다.

- 슬라이드가 매우 빠르게 바뀌면 일부 페이지를 놓칠 수 있습니다.
- 짧게 나타나는 애니메이션이나 전환 화면은 의도적으로 제외될 수 있습니다.
- 화면 구성이 특이하면 자동 슬라이드 영역 감지가 정확하지 않을 수 있으며, 이 경우 `--roi` 사용을 권장합니다.
- 결과물은 이미지 기반 PDF입니다. 원본 PowerPoint처럼 개별 텍스트나 도형을 편집할 수 있는 형태로 복원하지는 않습니다.
- 음성 전사, OCR, 강의 사이트 로그인/다운로드 기능은 포함하지 않습니다.
