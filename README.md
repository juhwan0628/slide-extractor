# Slide Extractor CLI 0.5.0b2

Extract slide PDFs from local lecture videos using the shared keyframe engine.

Requires Python 3.12+, FFmpeg and FFprobe on PATH. qpdf is optional.

```bash
python -m pip install "https://github.com/juhwan0628/slide-extractor/releases/download/v0.5.0b2/slide_extractor-0.5.0b2-py3-none-any.whl"
slide-extractor lecture.mp4 --json detailed
slide-extractor first.mp4 second.mp4 --output-dir slides
```

Development source: https://github.com/juhwan0628/slide-extractor-gui
This repository is generated from a verified source commit. See source-manifest.json for provenance and file hashes. Make core changes in the development repository, then export a new snapshot.

Default Python wheels omit the native keyframe helper and use the existing CPU fallback when no helper is configured. See [CLI usage](docs/cli.md).

## Migrating from the legacy 0.1.0 CLI

The previous implementation remains available through Git history and the legacy preservation branch. This update keeps the repository's history while replacing the FPS-based implementation with the shared keyframe engine.

| Legacy 0.1.0 | Current CLI |
|---|---|
| `python -m slide_extractor lecture.mp4` | `slide-extractor lecture.mp4` or `python -m slide_cli lecture.mp4` |
| `output/lecture.slides.pdf` | `lecture.slides.pdf` next to the input by default |
| PDF and JSON generated by default | PDF by default; add `--json simple` or `--json detailed` |
| `--sample-fps`, detector/dedup mode options | Removed; current keyframe and spatial detection policies are used |
| `--export-frames`, `--keep-workdir`, `--diagnostics` | Not provided by this CLI |
| JSON schema from the legacy detector | Current simple navigation or detailed keyframe schema; not a drop-in schema replacement |
| qpdf required in old setup instructions | qpdf optional; FFmpeg and FFprobe required |

`-o/--output` still selects a PDF destination. Multiple videos use `--output-dir`.
Read [CLI usage](docs/cli.md) for coordinates, overwrite behavior, exit codes and Windows UTF-8 automation.
